This tutorial aims to demonstrate how to use the miREA methods individually.
miREA integrates 9 methods, namely TG-ORA, TG-Score, MiR-ORA, MiR-Score, Edge-ORA, Edge-Score, Edge-2Ddist, Edge-Topology, and Edge-Network.

Each .rmd file named after a method contains a tutorial on how to use that method.

In these tutorials, we use the BLCA data as an example, including:\
(1) Differential gene expression analysis result: data/raw_data/cancer_data/DEG/BLCA_DEG.csv\
(2) Differential miRNA expression analysis result: data/raw_data/cancer_data/DEmiR/BLCA_DEmiR.csv\
(3) Gene read count matrix for tumor primary samples: data/raw_data/cancer_data/paired/BLCA_gene_TP.csv\
(4) miRNA read count matrix for tumor primary samples: data/raw_data/cancer_data/paired/BLCA_mir_TP.csv

However, not all methods always require all data to be available. You could find more details in each method's tutorial.
